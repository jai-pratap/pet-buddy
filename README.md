# Pet Buddy 

A responsive, static pet-community website designed for GitHub Pages.

## Included features
- Responsive landing page and navigation
- Pet adoption cards with search, animal/age filters and locally saved favourites
- Rescue report form that saves a copy in browser storage and downloads a shareable text report
- Lost & Found notices saved locally and downloadable for sharing
- Veterinary map search link
- Pet-care guidance and locally stored care reminders
- NGO/shelter discovery links and donation-safety guidance

## Run locally
Open `index.html` in a browser. No build tools or server are required.

## Publish with GitHub Pages
1. Create or open a GitHub repository.
2. Upload `index.html`, `styles.css`, `app.js`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.

## Important limitations
This is a front-end demo. Browser storage is device/browser-specific; reports and notices are not sent to NGOs or shared publicly. The pet profiles are sample cards, not verified live adoption listings. Map and NGO links open external searches. No payments are collected. Connect a trusted backend and verified organisation data before using it for real rescue dispatch, public listings, or donations.
