# Pet Buddy 3.0

A responsive, static pet-community website designed for GitHub Pages. This release keeps the Pet Buddy 2.0 layout, colour palette, sections and existing interactions.

## What's new in 3.0
- The golden dog in the hero photo performs a small, periodic hop.
- The animation is subtle; the photo frame and surrounding layout stay in place.
- The animation is disabled when a visitor has enabled the operating system's reduced-motion accessibility setting.
- Updated page title and footer version label.

## Included features
- Responsive landing page and mobile navigation
- Pet adoption demo cards with search, animal/age filters and locally saved favourites
- Rescue report form that saves a copy in browser storage and downloads a shareable text report
- Lost & Found notices saved locally and downloadable for sharing
- Veterinary map search link
- Pet-care guidance and locally stored care reminders
- NGO/shelter discovery links and donation-safety guidance

## Run locally
Open `index.html` in a browser. No build tools or server are required.

## Publish with GitHub Pages
1. Extract this ZIP.
2. Upload `index.html`, `styles.css`, `app.js`, and `README.md` to the root of your GitHub repository, replacing the previous versions.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.

## Important limitations
This remains a front-end community demo. Browser storage is device/browser-specific; reports and notices are not sent to NGOs or shared publicly. Pet profiles are sample cards, not verified live adoption listings. Map and NGO links open external searches. No payments are collected, and the rescue form does not dispatch rescuers. A trusted backend and verified organisation data are needed for real public listings, rescue dispatch, accounts, messaging or donations.
